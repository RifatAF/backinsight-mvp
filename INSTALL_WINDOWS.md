# Установка на Windows (5 минут)

Деньги виртуальные, данные живые с Bybit. Реальные ордера не отправляются, ключи API не нужны.

1. Распакуйте архив в простую папку, например `C:\backinsight`. Не в «Загрузки» и не на рабочий стол с OneDrive.
2. Двойной щелчок по **`install_windows.bat`**.
   - Если Python нет, скрипт поставит его сам через winget. Если не получится, поставьте Python 3.12 с python.org (галочка «Add python.exe to PATH») и запустите `install_windows.bat` снова.
   - Если Windows пишет «Защитник Windows предотвратил запуск», нажмите «Подробнее», затем «Выполнить в любом случае».
   - Когда Windows спросит права администратора, нажмите «Да». Они нужны, чтобы создать задачу автозапуска.
3. В конце должно быть написано `Состояние задачи: Running`. Всё, бот работает в фоне без окна.

## Что будет при выключении

- **Выключили, перезагрузили, обновилась Windows, села батарея:** бот стартует сам через минуту после включения, даже если вы не вошли в систему. Пропущенные дни он догонит сам.
- **Ноутбук уснул:** Windows разбудит его в 00:03 UTC (03:03 МСК) для дневного цикла. После пробуждения сторож проверяет бот каждые 10 минут.
- **От сети** ноутбук больше не засыпает, а закрытая крышка его не усыпляет. От батареи поведение прежнее. Не трогать настройки питания: `laptop\autostart_windows.ps1 -NoPower`.
- **Вылетел бот:** перезапуск через минуту. Два экземпляра одновременно не запустятся.

Лучше держать ноутбук подключённым к сети и интернету, особенно около 03:00 МСК.

## Проверка

Двойной щелчок по **`check_windows.bat`**: состояние задачи, сколько дней обработано, капитал моделей и последние строки лога. В первые сутки дней будет 0, это нормально: первый цикл пройдёт после 03:05 МСК.

## Через 3 месяца

Двойной щелчок по **`export_windows.bat`**. Откроется папка с файлом `abtest_export_ДАТА.zip`. Пришлите его мне. Резервный архив также создаётся сам 1-го числа каждого месяца в `abtest\exports`.

## Если Bybit недоступен

Если при установке в проверке написано `[НЕДОСТУПНО] bybit`, а `okx` в порядке: удалите папку `abtest` и запустите в этой папке `cmd`, затем `install_windows.bat -Exchange okx`.

## Остановить

PowerShell от администратора: `Unregister-ScheduledTask -TaskName backinsight-abtest -Confirm:$false`. Данные в папке `abtest` останутся.
