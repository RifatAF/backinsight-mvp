# Интеграция Google Stitch (MCP)

[Google Stitch](https://stitch.withgoogle.com) — AI-инструмент от Google Labs (на базе Gemini),
который генерирует UI-экраны, компоненты и код по текстовому описанию. Он не публикует
собственный официальный MCP-сервер, но предоставляет API, к которому подключается community-пакет
[`@_davideast/stitch-mcp`](https://github.com/davideast/stitch-mcp). Он оборачивает Stitch API в
MCP-сервер, поэтому Claude Code (и другие MCP-клиенты) могут напрямую запрашивать дизайны,
скачивать код экранов и превращать их в сайт.

Конфигурация сервера уже добавлена в [`.mcp.json`](../.mcp.json) в корне репозитория — при запуске
Claude Code в этом проекте сервер `stitch` подключится автоматически, если настроена аутентификация
(см. ниже).

## Аутентификация

Нужен доступ к Google Cloud проекту с включённым Stitch API и биллингом. Один из двух вариантов:

### Вариант A — API-ключ (быстрее всего)

1. Установите пакет один раз, чтобы получить CLI: `npx @_davideast/stitch-mcp init`
2. Мастер проведёт через вход в Google, выбор/создание проекта и включение Stitch API, либо
   можно выпустить API-ключ вручную в Google Cloud Console.
3. Экспортируйте ключ перед запуском Claude Code:
   ```bash
   export STITCH_API_KEY="<ваш-ключ>"
   ```
   `.mcp.json` подставит переменную окружения `STITCH_API_KEY` в конфигурацию сервера.

### Вариант B — системный gcloud / OAuth

Если у вас уже настроен `gcloud` с доступом к нужному проекту:

```bash
export STITCH_USE_SYSTEM_GCLOUD=1
export STITCH_PROJECT_ID="<id-проекта>"   # или GOOGLE_CLOUD_PROJECT
```

`stitch-mcp` использует текущие credentials `gcloud` вместо отдельного ключа.

Проверить, что всё настроено корректно, можно командой:

```bash
npx @_davideast/stitch-mcp doctor
```

## Что доступно из Claude Code

После подключения сервера MCP-инструменты позволяют:

- `get_screen_code` — получить HTML/код конкретного сгенерированного экрана;
- `get_screen_image` — получить скриншот экрана (base64);
- `build_site` — собрать статический сайт (Astro) из набора экранов Stitch, сопоставив их с маршрутами.

Есть также отдельный CLI (не через Claude), полезный для локальной разработки:
`npx @_davideast/stitch-mcp serve -p <project-id>` поднимает Vite dev-сервер с экранами проекта.

## Важно

`stitch-mcp` — независимый community-проект, не аффилированный с Google. Он требует включённого
биллинга в Google Cloud, так как обращается к платному Stitch API. Ключи/токены не должны попадать
в репозиторий — храните их только в переменных окружения локально или в секретах CI.
