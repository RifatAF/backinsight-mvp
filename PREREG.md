# Предрегистрация форвард-теста (зафиксировано 2026-11-11, до получения форвард-данных)

Правила взяты из независимого аудита (AUDIT.md). Меняются только новым коммитом с причиной; анализ экспорта делается
строго по этому файлу (`python stats_lab.py forward <экспорт.zip> <replay тех же дней>`).

## Что считается данными вне выборки
Только дни с 2026-11-11. Всё, что раньше (2018–2026), использовалось при разработке и в оценку «работает ли» не входит.
Дни catchup (ноутбук был выключен, сделки задним числом по закрытию) из оценки исключаются.

## Через 3 месяца (≈ 2027-02-11): что проверяем
1. **Совпадение с моделью.** Replay того же кода за те же дни против живого счёта: корреляция дневных доходностей
   ≥ 0.95 и расхождение итога ≤ 3 п.п. Не прошла — стратегия «сломана» (исполнение/данные), дальше не оцениваем.
2. **Поломка.** Итог за период ниже 1% квантиля той же длины окон в replay → «поломка или смена режима».
3. **Победителя по доходности за 3 месяца не выбираем.** За 90 дней ошибка Sharpe ≈ 2; лидером почти всегда будет
   стратегия с наибольшим плечом. Рейтинг на панели — для наблюдения, не для решения.

## Через 12 месяцев: заранее названные гипотезы (поправка Холма на 3 сравнения)
- H1: MEGA_SAFE > M1 по Sharpe.
- H2: TREND > 0 (Sharpe), и не хуже M1.
- H3: FNEG > 0 (Sharpe) без учёта carry.
Остальные стратегии — описательно, без выводов о превосходстве.

## Решение о реальных деньгах
Только стратегии, прошедшие пп. 1–2, с дефлированным Sharpe (N = 500) > 0.5 по объединённым replay + форвард,
сначала спот или плечо ≤ 1.5, минимальная сумма, 3 месяца сверки paper ↔ live.
