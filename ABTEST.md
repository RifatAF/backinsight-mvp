# A/B-тест четырёх моделей на живых данных Bybit

`abtest.py` ведёт 4 виртуальных счёта с одинаковым капиталом. Каждый день после закрытия свечи все четыре модели получают одни и те же живые данные Bybit и решают, что держать. Сделки исполняются виртуально, по текущему стакану Bybit с комиссией 0.1%. Реальные ордера не отправляются никогда.

| Модель | Логика |
|---|---|
| M1 | система, как построена (`system.py`, режим A): в бычьем рынке BTC чистый тренд, иначе 4 слоя |
| M2 | риск-менеджмент: режим B (размер по волатильности), трейлинг-стоп 25% по каждой монете, при просадке портфеля больше 20% экспозиция ×0.5 |
| M3 | один вход в лучший момент по данным: MVRV < 1 или цена ниже 200-недельной средней, иначе первый трендовый сигнал; дальше держать без продаж |
| M4 | онлайн-ML: логистическая регрессия, каждый день дообучается на всей истории, прогнозирует рост за 7 дней; позиция = сглаженная уверенность × размер по волатильности |

## Запуск

```bash
pip install pandas numpy ccxt
python abtest.py init --capital 10000 --coins BTC,ETH       # BTC обязателен (на нём режим рынка)
python abtest.py loop                                       # снимок рынка каждый час, дневной цикл в 00:05 UTC
python abtest.py report                                     # в любой момент: сравнение моделей
python abtest.py dataset                                    # таблица для анализа и дообучения
```

Альтернатива `loop` через cron:

```
5 * * * *  cd /путь && python3 abtest.py snapshot >> abtest/log.txt 2>&1
7 0 * * *  cd /путь && python3 abtest.py cycle    >> abtest/log.txt 2>&1
```

Если API Bybit у вас недоступен, используйте `init --exchange okx`: код тот же, данные OKX. Описание всех полей данных в `DATA_SCHEMA.md`.

## Проверка до запуска: те же модели по истории (`replay`, BTC + ETH, ноябрь 2023 – октябрь 2026)

| M2 | +97% | +25% | 0.96 | −23% | 323 |
| M3 | +70% | +19% | 0.60 | −59% | 2 |
| M4 | +48% | +14% | 0.70 | −29% | 772 |

M4 в первой версии (16 признаков, бо́льший вес свежих данных) дала −13%: она переобучалась. Нынешний вариант (6 трендовых признаков, вся история с равными весами, сглаживание) выбран на 2018–2023 годах и проверен на 2023–2026.
