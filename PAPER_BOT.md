# Торговый бот для Bybit: бумажный счёт и основной счёт

`paper_bot.py` торгует по итоговой системе из `system.py`. Логика:
- **Тренд:** BTC вырос за 30 дней и RSI монеты выше 50.
- **Размер позиции:** по волатильности.
- **Слои:** режим цикла по MVRV и ончейн-подтверждения.
- **Переключатель по рынку BTC:** в быке агрессивно, иначе осторожно.

Решения принимаются раз в день по закрытой дневной свече (00:00 UTC, 03:00 МСК). Основной счёт используется только в режиме `live` и только в пределах выделенного бюджета.

## Установка

```bash
pip install pandas numpy ccxt
```

## Бумажный счёт (без ключей)

```bash
python paper_bot.py reset --capital 10000 --coins BTC,ETH --system A   # A: максимум доходности, B: ровнее
python paper_bot.py signals                                            # что система думает сейчас
python paper_bot.py run                                                # один цикл (запускать раз в день после 00:00 UTC)
python paper_bot.py loop                                               # или оставить работать: цикл каждый день в 00:05 UTC
python paper_bot.py status                                             # капитал, просадка, сравнение с держанием, сделки
python paper_bot.py replay --days 1095                                 # прогон бота по прошлым 3 годам тем же кодом
```

Файлы в папке `paper/`:
- `state.json`: кэш и позиции;
- `trades.csv`: все сделки;
- `equity.csv`: капитал по дням и держание для сравнения.

Сделки исполняются по цене закрытия с комиссией 0.1% и проскальзыванием 0.05%.

## Тестнет Bybit (реальные ордера на тестовых деньгах)

1. Зарегистрироваться на testnet.bybit.com, получить тестовые USDT и создать API-ключ.
2. Задать ключи и запустить:

```bash
export BYBIT_TESTNET_KEY=...  BYBIT_TESTNET_SECRET=...
python paper_bot.py run --mode testnet
```

Если API Bybit недоступен из вашего региона, цены можно брать с другой биржи: `--exchange okx`. Тестнет при этом всё равно нужен Bybit.

## Основной счёт Bybit (реальные деньги)

1. **API-ключ.** Создайте на Bybit отдельный ключ: права только Spot Trade, **без вывода средств**, привязка к IP вашего компьютера. Надёжнее всего сделать отдельный субаккаунт с суммой, которую не жалко.
2. **Бюджет.** Выделите боту бюджет. Бот проверит, что на споте столько свободных USDT, и будет распоряжаться только этой суммой и купленными на неё монетами:

```bash
export BYBIT_API_KEY=...  BYBIT_API_SECRET=...
python paper_bot.py reset --mode live --capital 300 --coins BTC,ETH --system A --dir live
```

3. **Пробный прогон.** Бот покажет, какие ордера отправил бы, но ничего не отправит:

```bash
python paper_bot.py run --mode live --dir live
```

4. **Реальная торговля** раз в день после 00:00 UTC (через cron или `loop`):

```bash
python paper_bot.py run --mode live --dir live --confirm-live
python paper_bot.py loop --mode live --dir live --confirm-live
```

Защиты:
- **Лимитные IOC-ордера:** проскальзывание не больше 0.3%, неисполненный остаток отменяется и добирается на следующем цикле.
- **Объём покупки** считается по худшей цене лимита, поэтому бот не выходит за бюджет.
- **Продажа** не больше, чем бот сам купил. Чужие монеты на счёте бот не трогает.
- **Нет торговли,** если последняя закрытая свеча старше суток или текущая цена ушла от закрытия больше чем на 15%.
- **Аварийная остановка:** `touch live/STOP` останавливает торговлю, удалите файл, чтобы возобновить. Позиции при этом не закрываются, их можно продать вручную.
- **Журнал:** каждое исполнение записывается в `live/trades.csv` с фактической ценой и комиссией.

Начните с маленькой суммы и сверьте первые сделки в `trades.csv` с историей ордеров на Bybit. Режим live проверен на имитации биржи, но не на реальном Bybit: из среды разработки API Bybit недоступен.

## Автозапуск раз в день (cron, Linux/macOS)

```
5 0 * * *  cd /путь/к/backinsight-mvp && python3 paper_bot.py run >> paper/bot.log 2>&1
5 0 * * *  cd /путь/к/backinsight-mvp && python3 paper_bot.py run --mode live --dir live --confirm-live >> live/bot.log 2>&1
```

## Чего ждать (по `robustness.py`)

| | BTC + ETH, режим A | BTC + ETH, режим B |
|---|---|---|
| Годовая доходность в истории с 2017 | около +60% | около +43% |
| Максимальная просадка | около −28% | около −25% |
| Бутстрэп 3 лет: годовая доходность, перцентили 5 / 50 / 95 | +8% / +60% / +157% | +6% / +43% / +105% |
| Бутстрэп 3 лет: шанс убытка | 2% | 2% |

Чем раньше после закрытия дня сделана сделка, тем лучше. Задержка на один день увеличивала просадку с −28% до −44%. История не гарантирует будущий результат.
