# Predictive Lab

Скрипт `predictive_lab.py` проверяет, какие индикаторы, метрики, связки и сезонность предсказывают направление цены вне выборки. Зависимости: `pip install pandas numpy`.

```bash
python predictive_lab.py fetch --coin BTC --days 730      # -> data/BTC_4H.csv
python predictive_lab.py run data/BTC_4H.csv              # горизонты 4ч, сутки, неделя
python predictive_lab.py run data/BTC_4H.csv --pairs      # + все попарные произведения признаков
```

Данные: свечи 4H и open interest с OKX, funding с Hyperliquid (Binance и Bybit отдают 403 в некоторых регионах). Бесплатный OI есть только примерно за последние 240 дней, поэтому для OI-признаков выборка короче (колонка `n_eff`). Можно подать свой CSV: обязательны `timestamp` и `close`, остальные колонки (`volume`, `funding`, `oi`, любые свои, например long/short ratio или ликвидации) подхватятся автоматически.

## Что проверяется

| Группа | Признаки |
|---|---|
| Индикаторы | momentum 1/6/42 бара, RSI 14, MACD hist, Bollinger z, расстояние до MA200, волатильность, объём |
| Деривативы | funding, funding z-score, изменение funding, изменение OI, OI z-score |
| Связки | funding_z × изменение OI (перегрев плеча), funding_z × OI z, momentum × изменение OI, funding_z × momentum, объём × momentum, режимы «цена ± / OI ±» и «funding низкий/средний/высокий» |
| Сезонность | час, день недели, месяц, день недели × час |

## Как считается

Walk-forward: история режется на 5 кусков, правило подбирается только на прошлом (знак корреляции и медиана для чисел, средняя доходность по категории для сезонности и режимов), проверяется на следующем куске, между ними зазор в длину горизонта. Метрики в таблице: `hit` (доля угаданных направлений), `baseline` (всегда ставить на большинство), `edge = hit − baseline`, `ic` (ранговая корреляция), `bps` (средняя доходность в направлении сигнала), `stable` (в скольких кусках edge > 0), `significant` (p ниже порога Бонферрони). Перекрывающиеся окна учтены через `n_eff = N / горизонт`.

Сигнал стоит смотреть, только если одновременно edge > 0, stable почти во всех кусках и значимость выдерживает поправку на число проверок. Сезонность по месяцам на двух годах данных статистически пустая: на каждый месяц приходится одно-два наблюдения.
