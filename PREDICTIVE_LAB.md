# Predictive Lab

Скрипт `predictive_lab.py` проверяет, какие индикаторы, деривативные метрики, связки и сезонность предсказывают направление цены вне выборки. Зависимости: `pip install pandas numpy ccxt`.

```bash
python predictive_lab.py fetch --coin ETH --tf 1h,4h,1d                         # -> data/ETH_<tf>.csv
python predictive_lab.py run data/ETH_1h.csv data/ETH_4h.csv data/ETH_1d.csv   # все таймфреймы сразу
python predictive_lab.py run data/ETH_4h.csv --pairs                            # + все попарные произведения
```

## Данные (через ccxt)

| Метрика | Источник | Глубина бесплатной истории |
|---|---|---|
| Свечи перпа | OKX `ETH/USDT:USDT` | 2 года (1h, 4h), 4 года (1d) |
| Премия Coinbase | Coinbase `ETH/USD` / OKX спот `ETH/USDT` − 1 | как у свечей |
| Funding | Hyperliquid, почасовой, сумма за бар | с 2023 |
| Open interest | OKX trading data | ~30 дней (1h), ~240 дней (4h), ~2.8 года (1d) |
| Long/short аккаунтов, long/short топ-трейдеров | OKX trading data | как OI |
| Taker buy/sell volume | OKX trading data | ~240 дней (4h); на 1d API отдаёт только 100 дней |

Binance и Bybit блокируют запросы из части регионов, поэтому по умолчанию используются OKX, Coinbase и Hyperliquid. Можно подать свой CSV: обязательны `timestamp` и `close`, остальные колонки подхватятся автоматически, а любые незнакомые числовые станут признаками `user_*`.

## Что проверяется

| Группа | Признаки |
|---|---|
| Индикаторы | momentum 1/6/42 бара, RSI 14, MACD и гистограмма, Bollinger z, расстояние до MA200, волатильность, объём, диапазон бара |
| Деривативы | funding (уровень, z-score, изменение), OI (изменение, z-score), long/short толпы и топ-трейдеров, дисбаланс taker-объёма |
| Спот | премия Coinbase (уровень, z-score, изменение) |
| Связки | funding × OI (перегрев плеча), momentum × OI, премия Coinbase × funding (спот США против перпа), long/short × OI, long/short × funding, taker × OI, топы против толпы, MACD × объём, RSI × волатильность; режимы цена ±/OI ±, funding и премия низкая/средняя/высокая |
| Сезонность | час, день недели × час (внутри дня), день недели, месяц |

## Как считается

Каждый признак проверяется на собственной истории, ведь у OI и long/short она короче, чем у цены. История режется walk-forward на 5 кусков. Правило подбирается только на прошлом: для чисел это знак корреляции и медиана, для категорий средняя доходность. Проверка идёт на следующем куске, между ними зазор в длину горизонта.

Колонки таблицы:
- `hit`: доля угаданных направлений;
- `baseline`: доля при ставке всегда на большинство;
- `edge`: hit − baseline;
- `ic`: ранговая корреляция с будущей доходностью;
- `bps`: средняя доходность в направлении сигнала;
- `stable`: в скольких кусках edge > 0;
- `days`: длина истории признака;
- `sig ***`: p ниже порога Бонферрони.

Перекрывающиеся окна учтены через `n_eff = N / горизонт`.

Сигнал стоит смотреть, если одновременно edge > 0, stable почти во всех кусках, n_eff в сотнях и признак держится на соседних горизонтах или таймфреймах. Сезонность по месяцам на двух годах статистически пустая: на каждый месяц приходится одно-два наблюдения.

# Strategy Lab

`strategy_lab.py` перебирает торговые стратегии на дневках ETH с 2019 года и честно проверяет, переносится ли результат на новые данные.

```bash
python strategy_lab.py fetch --coin ETH     # -> data/ETH_daily_full.csv
python strategy_lab.py run --fee 0.001      # 0.1% издержек на каждую смену позиции
```

Данные: цены ETH и BTC (Coinbase), премия Coinbase, funding Deribit с 2019, DVOL (опционная волатильность Deribit), Fear & Greed, стейблкоины и TVL (DefiLlama), ончейн Coin Metrics (MVRV, активные адреса, транзакции, потоки и запас на биржах), OI и long/short OKX, макро FRED, если доступен. Ончейн, DeFi и макро сдвинуты на день из-за задержки публикации.

Около 60 стратегий шести семейств (тренд, возврат к среднему, деривативы, ончейн, сентимент и опционы, макро) в версиях long/short и long-only. К ним добавляются пары лучших: согласие двух сигналов (AND), среднее двух (SUM) и фильтр по тренду (FILTER). Проверки:
- Sharpe на первых 60% истории и на последних 40%;
- таблица устойчивых стратегий (Sharpe > 0.5 в обеих частях);
- deflated Sharpe с поправкой на число попыток;
- walk-forward: каждые 90 дней берётся лучшая стратегия за прошлые 2 года и торгуется дальше. Это честная оценка всей процедуры «перебрать и выбрать».
